# Grille STARD (2015) — études de performance diagnostique

30 items. Vocabulaire : le **test index** est le test évalué ; le **standard de référence** est la meilleure méthode disponible pour établir la présence de la **condition cible**.

En EDS, le test index est le plus souvent un résultat de laboratoire, un score ou un algorithme sur les données (phénotype à partir de codes PMSI, règle sur le texte), et le standard de référence une relecture de dossiers, une anatomopathologie ou un registre. Le piège principal est le **biais de vérification** : quand le standard de référence n'a été réalisé que chez les patients dont le test index était positif, la sensibilité et la spécificité calculées sur les seuls patients vérifiés sont fausses.

| Item | Section | Ce qu'il faut rapporter | En EDS |
|---|---|---|---|
| 1 | Titre ou résumé | L'étude est identifiée comme une étude de performance diagnostique, avec au moins une mesure (sensibilité, spécificité, valeurs prédictives, AUC). | Ajouter « sur données de l'entrepôt de données de santé » ; dire si le test index est un algorithme sur les données. |
| 2 | Résumé | Résumé structuré : schéma, méthodes, résultats, conclusions. | Donner la prévalence de la condition cible dans l'échantillon, la sensibilité et la spécificité avec IC ; aucun effectif < 10. |
| 3 | Introduction | Le contexte scientifique et clinique, y compris l'usage prévu et le rôle du test index (remplacement, triage, ajout). | Pour un phénotype : usage prévu (sélection d'une cohorte, détection d'un événement) et pourquoi les codes seuls ne suffisent pas. |
| 4 | Introduction | Les objectifs et les hypothèses. | Objectif de VPP ou de sensibilité fixé à l'avance dans `01-question.md` (par exemple VPP ≥ 0,85 pour une cohorte d'inclusion). |
| 5 | Méthodes – Schéma | Si le recueil a été planifié avant la réalisation du test index et du standard de référence (prospectif) ou après (rétrospectif). | Presque toujours rétrospectif : les résultats du test index existaient dans l'entrepôt avant l'étude ; dire si le standard de référence (relecture) a été fait pour l'étude. |
| 6 | Méthodes – Participants | Les critères d'éligibilité. | Population sur laquelle le test sera utilisé (tous les séjours d'un service, une période) et non seulement les patients ayant eu le standard de référence. |
| 7 | Méthodes – Participants | Sur quelle base les participants potentiellement éligibles ont été identifiés (symptômes, tests antérieurs, registre). | Requête de sélection sur l'EDS : codes, service, période ; préciser si le test index a servi à sélectionner (biais de vérification). |
| 8 | Méthodes – Participants | Où et quand ils ont été identifiés (cadre, lieu, dates). | Hôpital, services, fenêtre de dates, date du snapshot ; version du logiciel de codage ou de l'automate de laboratoire sur la période. |
| 9 | Méthodes – Participants | Si les participants forment une série consécutive, aléatoire ou de convenance. | Tirage aléatoire des dossiers à relire (avec la graine et la méthode) ou série consécutive ; une série de convenance doit être justifiée. |
| 10a | Méthodes – Tests | Le test index, avec assez de détail pour être reproduit. | Pour un algorithme : codes, positions (DP/DR/DAS), fenêtres, logique, version ; pour une biologie : analyte, méthode, automate, unité. |
| 10b | Méthodes – Tests | Le standard de référence, avec assez de détail pour être reproduit. | Grille de relecture de dossiers, qualification des relecteurs, résolution des désaccords ; ou source externe (registre, anatomopathologie) et son chaînage. |
| 11 | Méthodes – Tests | La justification du choix du standard de référence quand d'autres existent. | Pourquoi la relecture de dossiers plutôt qu'un registre ou un autre code ; limites connues du standard choisi. |
| 12a | Méthodes – Tests | La définition et la justification des seuils de positivité ou des catégories du test index, en distinguant préspécifié et exploratoire. | Seuil de biologie ou nombre minimal de codes fixé avant l'analyse ; définitions étroite et large annoncées dans `05-plan-analyse.md`. |
| 12b | Méthodes – Tests | La définition et la justification des seuils ou catégories du standard de référence, en distinguant préspécifié et exploratoire. | Critère de « cas confirmé » de la grille de relecture (par exemple diagnostic explicite dans le compte rendu + traitement) fixé à l'avance. |
| 13a | Méthodes – Tests | Si les informations cliniques et les résultats du standard de référence étaient connus de ceux qui réalisaient ou lisaient le test index. | Un algorithme automatique ne voit rien : le dire ; mais le codeur PMSI qui a produit les codes avait accès au dossier complet. |
| 13b | Méthodes – Tests | Si les informations cliniques et les résultats du test index étaient connus de ceux qui évaluaient le standard de référence. | Relecteurs en aveugle du résultat de l'algorithme ou non ; masquage des codes dans l'interface de relecture si possible. |
| 14 | Méthodes – Analyse | Les méthodes d'estimation ou de comparaison des mesures de performance. | Sensibilité, spécificité, VPP, VPN avec IC exact ou de Wilson ; correction du biais de vérification si le standard n'a été appliqué qu'à une partie des patients (échantillonnage stratifié par résultat du test index et pondération inverse). |
| 15 | Méthodes – Analyse | Le traitement des résultats indéterminés du test index ou du standard de référence. | Dossiers illisibles, codes ambigus, biologie hors bornes : comptés positifs, négatifs ou exclus, et l'analyse de sensibilité correspondante. |
| 16 | Méthodes – Analyse | Le traitement des données manquantes pour le test index et le standard de référence. | Patients sans le test (biologie non prescrite) : exclus ou traités comme négatifs ; part de dossiers non retrouvés pour la relecture. |
| 17 | Méthodes – Analyse | Les analyses de variabilité de la performance (sous-groupes, lecteurs, centres), en distinguant préspécifié et exploratoire. | Performance par service, par année (dérive de codage), par sexe et classe d'âge ; annoncé dans `05-plan-analyse.md`. |
| 18 | Méthodes – Analyse | L'effectif prévu et sa justification. | Nombre de dossiers à relire pour obtenir une largeur d'IC donnée sur la VPP et sur la sensibilité, compte tenu de la prévalence attendue dans `04-faisabilite.md`. |
